# Как запустить и показать ITDesk

Теперь ты показываешь одно приложение: создаёшь заявку, смотришь её документ в MongoDB, меняешь статус и запускаешь обработку кнопками. Отдельные команды аналитики для показа не нужны.

## Перед показом

1. Открой папку `C:\Users\Nero\Desktop\itdesk` через Проводник Windows.
2. Дважды нажми `start.bat`.
3. Подожди появления окна входа. Консоль запуска не закрывай, пока работаешь с приложением.
4. Войди: логин `tech`, пароль `tech123`, если ты его не менял.

Если Windows скрывает расширения файлов, файл может называться просто `start`. Это файл команд Windows, который лежит рядом с `run_app.py`.

Альтернативный запуск из терминала VS Code:

```powershell
cd C:\Users\Nero\Desktop\itdesk
python run_app.py
```

При первом запуске старая заявка и пользователи переносятся в MongoDB. Исходный `itdesk.db` остаётся на месте. Дальше приложение работает с MongoDB.

## Что показать и что говорить

### Создать заявку

Скажи: «Это программа заявок технической поддержки. Все рабочие данные хранятся в MongoDB».

Нажми «Новая заявка». Введи:

| Поле | Пример |
| --- | --- |
| Тема | Не работает проектор |
| Аудитория | 205 |
| Категория | Проектор |
| Приоритет | Высокий |
| Описание | Проектор включается, но изображение не появляется |

Нажми «Отправить». Заявка появится в таблице. Источник «Пользователь» означает обычную заявку, созданную в приложении.

### Показать настоящий документ MongoDB

Один раз нажми на строку заявки, затем «Документ MongoDB». Откроется окно с данными. Наверху указаны имя базы и коллекция `tickets`, внутри — документ заявки.

Скажи: «Это не отдельная копия для отчёта. Приложение прочитало документ заявки из MongoDB. Поле title — тема, status — состояние. comments и history — комментарии и история внутри того же документа».

Закрой окно документа. Открой заявку двойным нажатием на строку, нажми «Взять в работу». Добавь комментарий «Проверю подключение». Закрой карточку, снова открой «Документ MongoDB».

Скажи: «Теперь status стал in_progress, добавлены исполнитель, комментарий и история. Изменения сохранены в MongoDB».

### Показать поиск и удаление

В строку поиска введи часть темы, например «проектор», нажми Enter. Кнопкой выбора статуса можно дополнительно ограничить список. Чтобы вернуть все заявки, очисти строку поиска, выбери «Все статусы» и нажми «Обновить».

Для удаления создай отдельную ненужную заявку, выбери её, нажми «Удалить» и подтверди. Не используй для этого единственную важную заявку.

Скажи: «Создание, чтение, изменение и удаление — это CRUD-операции с документами MongoDB».

### Подготовить данные для обработки

Нажми «Обработка данных». В этом окне:

| Кнопка | Что делает |
| --- | --- |
| Учебные заявки | Добавляет до 1000 примеров, помеченных источником «Учебные». Повторное нажатие не дублирует существующие записи. |
| Импорт из API | Получает 200 учебных todo из интернета и сохраняет их в рабочую MongoDB. В списке источник — «Внешний API». |
| Очистка Pandas | Проверяет данные и создаёт очищенный снимок и выборку активных заявок. |
| Spark и SQL | Подсчитывает данные через RDD, DataFrame и SQL, проверяет совпадение, сохраняет планы запросов. |
| Hadoop MapReduce | Запускает настоящий Apache Hadoop Streaming для подсчёта активных заявок по категориям. |
| Проверить поиск | Сравнивает полный просмотр MongoDB с поиском через индекс. |
| Построить графики | Создаёт и показывает диаграммы по заявкам. |
| Выполнить обработку целиком | Выполняет Pandas, Spark/SQL, Hadoop, сравнение поиска и графики. Не добавляет новые учебные данные автоматически. |

Для наглядного показа нажми «Учебные заявки», подтверди и дождись «Готово». Затем нажми «Импорт из API» и дождись результата. Для импорта нужен интернет. При недоступном интернете можно показать остальные действия на уже сохранённых заявках.

Скажи: «Для демонстрации я добавляю помеченные учебные данные. Это не реальные обращения организации».

### Запустить обработку и показать графики

Нажми «Выполнить обработку целиком». Дождись «Готово»; кнопки временно отключены, чтобы не запустить несколько вычислений одновременно. Обычно вычисления занимают десятки секунд, время зависит от компьютера.

Когда работа закончится, в этом же окне появятся пояснения и три диаграммы.

Скажи: «Pandas подготовил данные. Spark обработал их несколькими способами и проверил одинаковый результат. Hadoop выполнил MapReduce. Затем программа сравнила поиск с индексом и без него и построила графики Matplotlib».

Покажи графики: категории проблем, статусы и приоритеты. В списке результатов выбери `dashboard.pdf` или `summary.csv` и нажми «Сохранить выбранный результат…», если нужно передать их преподавателю.

Изменения заявок не обновляют уже построенные графики автоматически. Для новых результатов повторно нажми кнопку обработки.

## Что означают названия

MongoDB — хранилище документов. PyMongo — средство, через которое Python читает и изменяет эти документы. API — способ получить данные из другой программы через интернет. Pandas — обработка таблиц. Spark — движок обработки данных; SQL — язык запросов к ним. Hadoop MapReduce — обработка через промежуточные пары «категория → количество». Matplotlib рисует графики.

Внутри всё связано с одними заявками: окно приложения → API → MongoDB → снимок заявок → Pandas/Spark/Hadoop → результаты в том же окне.

## Вопросы на защите

| Вопрос | Короткий ответ |
| --- | --- |
| Где хранится заявка? | В коллекции tickets основной MongoDB itdesk. |
| Зачем MongoDB, если есть файл itdesk.db? | Файл остался от старой версии как исходный резерв. После переноса новые данные идут в MongoDB. |
| Что делает индекс? | Помогает искать, просматривая меньше документов. Выигрыш зависит от запроса и данных. |
| Зачем несколько способов подсчёта? | Чтобы показать работу требуемых инструментов и проверить совпадение результатов. |
| Это кластер больших данных? | Нет. Hadoop и Spark здесь работают локально на одном компьютере. Показ демонстрирует технологии. |
| Можно показать работу без учебных примеров? | Да, можно создать свои заявки и обработать только их. |
| Почему обычный пользователь не видит все кнопки? | Обработка, просмотр документов и удаление доступны сотрудникам, а пользователь видит свои заявки. |

## Если что-то не запускается

Не закрывай консоль: в ней будет причина. Если указан старый сервер, останови ранее запущенный `run_server.py` сочетанием Ctrl+C и повтори `start.bat`. Если обработка показала ошибку, в окне можно сохранить `job.log`.

На текущем компьютере Java и Windows-компоненты Hadoop подготовлены; настоящий Hadoop проверен. На другом компьютере папку `.tools` нужно перенести отдельно или установить MongoDB, Java 17 и Hadoop с Windows-компонентами. Python-библиотеки устанавливаются командой `python -m pip install -r requirements.txt`. Подробности установки — в README.

Для завершения работы закрой окно ITDesk. Созданный запуском сервер остановится. MongoDB остаётся отдельным процессом; при необходимости её можно остановить командой `python -m analytics.stop_mongo`.
