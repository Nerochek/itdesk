## Полученные результаты

В MongoDB загружено 10200 записей: 10000 синтетических заявок с источником `demo` и 200 учебных todo с источником `jsonplaceholder`. Исходная SQLite-база ITDesk содержала 0 заявок. Учебные данные не представляют статистику организации.

Активные статусы — `new` и `in_progress`. Результаты локального MapReduce, Spark RDD, DataFrame и SQL совпали: account — 814, hardware — 838, network — 866, other — 918, projector — 883, software — 804. Всего 5123 активные записи.

Для поиска MongoDB `status=new, category=network` число просмотренных документов сократилось с 10200 до 445 (примерно в 22,9 раза), результаты совпали. Это не означает ускорение времени в 22,9 раза. Доказательство: `analytics_data/mongo_explain.json`.

Spark SQL: медиана трёх измерений после прогрева — 0.02545 секунды для исходного запроса и 0.02239 секунды для кэшированного. Построение кэша — 0.25471 секунды. Эти затраты нужно учитывать отдельно; кэш на небольшом наборе не гарантирует выигрыша. Измерения зависят от нагрузки, исходные значения находятся в `analytics_data/spark_sql.json`, планы — в `spark_plans.txt`.

Четыре проверки аналитики стандартным unittest прошли. Все 22 существующих теста ITDesk прошли. FastAPI выдал предупреждение об устаревающем использовании httpx; замена библиотек вне плана не выполнялась.

## Ограничение пункта 11

Настоящий Hadoop Streaming запускался через Java и завершился с кодом 1 до MapReduce из-за отсутствия `winutils.exe`. Официальный архив содержит Unix native-библиотеки, совместимых Windows native-компонентов в нём нет. Настройка Hadoop на этом компьютере не завершена; локальная проверка Python не считается выполненным заданием Hadoop.

Нужна совместимая Windows-сборка компонентов Hadoop (`winutils.exe`, при необходимости `hadoop.dll`) в `%HADOOP_HOME%/bin`, либо запуск подготовленных mapper/reducer в Linux-окружении Hadoop. Журнал: `analytics_data/hadoop_attempt.log`, статус: `analytics_data/hadoop_status.json`.

## Масштабирование

10200 записей — демонстрация, а не испытание на больших данных. Загрузка MongoDB идёт пакетами по 1000 документов. Pandas и графики загружают набор в память: для больших объёмов потребуются порционная очистка или перенос в Spark. Spark передаёт на драйвер только небольшой итог по категориям. `local[2]` означает два потока одного компьютера, а не кластер.
