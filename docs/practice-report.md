## Проверка работы

Все 29 тестов прошли. Итоговый снимок проверки: `analytics_data/verification.json`.

Проверяется настоящий MongoDB без подмены SQLite или имитации документов. Интеграционный сценарий создаёт отдельную тестовую базу, добавляет 1000 учебных заявок, повторно проверяет отсутствие дублей, импортирует 200 записей внешнего API и запускает весь цикл обработки через те же API, что вызывают кнопки интерфейса.

Для Hadoop проверяются код завершения, наличие `_SUCCESS` и совпадение подсчёта с контрольным алгоритмом. RDD, DataFrame и Spark SQL также должны дать одинаковые результаты. Qt-проверка открывает интерфейс в фоновом режиме, читает заявку из MongoDB, запускает обработку и проверяет появление изображения в окне.

Отдельно проверяются разграничение доступа, отсутствие частичного изменения при неверном исполнителе, удаление документа, поиск, перенос пользователей/комментариев/истории из SQLite, сохранение исходного файла и повторный запуск миграции без сброса правок.

## Данные и границы демонстрации

Рабочая база называется `itdesk`. При переходе обнаружены и перенесены три пользователя и одна старая заявка. SQLite больше не используется для новых данных. Тестовые базы изолированы и удаляются после проверки; пользовательские заявки не используются для испытаний с удалением.

Учебные записи и todo внешнего сервиса явно помечены источником. Они добавляются только отдельными кнопками. Полная обработка сама не наполняет базу. Графики относятся к снимку заявок на момент запуска, а не к автоматически обновляемой статистике.

Spark использует `local[2]`, Hadoop — standalone: вычисления настоящие, но это один компьютер, не распределённый кластер. Pandas загружает снимок в память. Небольшой учебный набор не доказывает производительность на больших данных; кэширование и индексы оцениваются по сохранённым планам и показателям, без обещания фиксированного ускорения.

## Использованный софт

Для хранения и обработки: Python, MongoDB, PyMongo, Pandas, Apache Hadoop, PySpark/Spark SQL, Matplotlib. Среда разработки — VS Code, контроль версий — существующий Git-репозиторий. Java 17 необходима для запуска Spark и Hadoop. PyQt6, FastAPI и requests сохранены из готового приложения как интерфейс и транспорт. Другие платформы обработки и СУБД не добавлены.

Windows-компоненты Hadoop 3.5.0 получены из открытой [сборки сообщества zehelh/winutils](https://github.com/zehelh/winutils/releases/tag/hadoop-3.5.0), контрольная сумма SHA256 сверена с метаданными релиза. Они не являются официальным бинарным релизом Apache. На другом компьютере эти зависимости необходимо перенести или подготовить заново.

Сценарий показа для начинающего пользователя находится в `docs/analytics-guide.md`. Запуск — `start.bat` или `python run_app.py`.
